## 🔥 Tại sao bạn sẽ làm tốt?

1.  **Bạn đã có kiến thức:** Bạn hiểu về cấu trúc thư mục, bạn biết cách tách *Function* và *Assertion*. Đó là tư duy của Senior!

3.  **Bạn có bản lĩnh:** Bug sinh ra là để bị tiêu diệt. Test case fail là cơ hội để làm script mạnh mẽ hơn.

## 💡 Bí kíp "Vượt Vũ Môn" (Tips for Success)

Để Project này đạt điểm tuyệt đối 10/10, hãy nhớ kỹ 3 thần chú này:

* **⚡ Code phải SẠCH (Clean Code):**
    * Đừng để code lộn xộn. Hãy sắp xếp folder *Function* và *Assertion* thật khoa học. Người khác nhìn vào phải thốt lên: *"Wow, tổ chức gọn gàng quá!"*
* **🎲 Dữ liệu phải ĐỘC LẬP (Data Independence):**
    * Đừng dùng lại dữ liệu cũ. Hãy để mỗi lần chạy là một bộ data mới tinh. Hãy để Script của bạn "tự lực cánh sinh".
* **🛡️ Assert phải CHẶT (Strong Assertions):**
    * Đừng chỉ verify hời hợt. Hãy kiểm tra từng trường thông tin, từng trạng thái active/inactive. Test càng kỹ, niềm tin càng lớn.

## ☕ Khi gặp bế tắc (Stuck)?

1.  Hít thở sâu, đứng dậy đi uống một cốc nước.
2.  Đọc lại log lỗi (Error Log) thật chậm.
3.  Debug từng bước một.
4.  Nhớ rằng: **Mọi vấn đề đều có cách giải quyết.**
